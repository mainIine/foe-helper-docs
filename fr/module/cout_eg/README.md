# Coût de l'Expédition de Guilde (EG)

{% hint style="success" %}
Ce module peut-être activé dans [parametres](../parametres/README.md#pop-up)
{% endhint %}

Le module **Coût de l'EG** s'affiche si le % de ressource nécessaire pour débloquer un niveau d'EG est supérieur à un seuil défini par le joueur.
